## 층 구성

27종과 묶음은 [신경망 구조 도감](https://adminmrobo.github.io/neural_network_atlas/0_neural_network_essence.html)을 따르고, 층은 쉬운 것부터 어려운 것 순으로 놓았습니다(1~9층 쉬움, 10~18층 보통, 19~27층 어려움).
경사하강법·학습률·배치·에포크처럼 "어떻게 배우는가"에 대한 내용은 로비와 [Fish Market 연구실](https://adminmrobo.github.io/fish_market_learning_epoch_etc/) 2장·3장으로 안내합니다.
원본 차트: Stefan Leijnen & Fjodor van Veen, "The Neural Network Zoo" (CC BY).

## 폴더 구조

```
.
├─ index.html          신경망 연구소 건물 (엘리베이터로 층 고르기)
├─ math_behind_ai/     로비
├─ chars3d/lab3d.js    연구실 식구 3D 모델 (fruitfly-lab-expressions 사본, 모든 층이 같이 씀)
└─ assets/             얼굴 그림
```

- 3D는 three.js 0.170을 CDN에서 불러옵니다.
- `chars3d/lab3d.js`의 원본은 [fruitfly-lab-expressions](https://github.com/adminmrobo/fruitfly-lab-expressions)입니다. 원본을 고치면 이 사본도 바꿉니다.
- 새 층을 열 때: 폴더를 하나 만들고(예: `floor_01_perceptron/`), `index.html`의 `FLOORS`에서 그 층 줄 끝에 주소를 적으면 "들어가기" 단추가 생깁니다. 위 표의 상태도 바꿉니다.

## 로비 참고

구성은 인포그래픽 「Mathematics Behind AI」(ML Tut)를 참고했습니다. 3D 장면과 설명문은 새로 만들었습니다. 화면의 수치는 개념 설명용 예시입니다.
