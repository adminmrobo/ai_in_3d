## 별관 · 잇기와 솎아 내기 · 복권 가설 (`annex/`)

건물 오른쪽의 낮은 건물입니다. 27층 NTM의 마지막 버튼과 건물 첫 화면의 엘리베이터에서 들어갑니다.

- 위층: 8겹으로 촘촘히 이어진 큰 그물
- ① 잇기: CNN→LSTM(사진 설명), 인코더→디코더(번역), 생성자↔판별자(GAN), RBM 쌓기(DBN)
- ② 깊이 쌓기: 겹마다 줄어드는 신호와 지름길(23층)
- ③ 연결 수: 겹 수·폭에 따른 연결 수, 자릿수 막대로 GPT-3까지 비교
- ④ 가지치기: 학습을 마친 그물에서 작은 연결을 잘라만 냈을 때의 경계와 정답률
- ⑤ 복권 가설: 반복 가지치기 후 처음 값 θ₀로 되돌려 학습 vs 새 무작위 값으로 학습

④·⑤의 숫자는 `annex/lt.js`(두 갈래 나선 데이터, 2-16-16-1 그물, 연결 304개)를 node로 돌려 만든 `annex/lt_data.js`의 값입니다. 씨앗 3개 결과를 모두 싣고, 새 무작위 값 쪽은 세 번의 평균과 각 값을 함께 보여 줍니다. 원 논문: Frankle & Carbin (ICLR 2019). 큰 신경망에서는 학습 초반 값으로 되돌려야 한다는 후속 연구(Frankle 외, ICML 2020)도 페이지에 적었습니다.

## 폴더 구조

```
.
├─ index.html          신경망 연구소 건물 (첫 화면: 건물 전체, 엘리베이터로 층 고르기)
├─ math_behind_ai/     로비
├─ floors/
│  ├─ index.html       층 페이지 하나 (주소 끝의 ?f=1 ~ ?f=27 로 층을 고름). 로비와 같은 구성: 상공의 설계도 + 구역 ①~⑤
│  ├─ data.js          층 순서·이름·설명·대사·구조 그림 명세 (건물 첫 화면도 같이 씀)
│  └─ demos.js         층별 실험 27개(⑤)와 구역 ①③④의 내용(EXTRA: 하는 일·핵심 부품·그래프 곡선)
├─ chars3d/lab3d.js    연구실 식구 3D 모델 (fruitfly-lab-expressions 사본)
└─ assets/             얼굴 그림
```

- 3D는 three.js 0.170을 CDN에서 불러옵니다.
- `chars3d/lab3d.js`의 원본은 [fruitfly-lab-expressions](https://github.com/adminmrobo/fruitfly-lab-expressions)입니다. 원본을 고치면 이 사본도 바꿉니다.
- 층의 순서나 문구를 바꿀 때는 `floors/data.js`의 `FLOORS`만 고치면 건물 첫 화면과 층 페이지에 함께 반영됩니다. 실험을 고칠 때는 `floors/demos.js`에서 그 층의 약어(예: `LSTM`)를 찾습니다.
- 실험의 숫자는 모두 페이지 안에서 계산합니다. 단순화한 실험은 화면의 실험 아래에 그 사실을 적어 두었습니다.
